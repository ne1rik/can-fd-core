# Комплект верификации CAN FD + RTL-ядро

Верификационное окружение и RTL-ядро CAN FD для симуляции на **Verilator + cocotb**. Коммерческие EDA-лицензии не требуются.

**Целевой протокол:** ISO 11898-1:2015. Свободная спецификация Bosch CAN FD 1.0 (2012) является *не-ISO* и сознательно не используется как эталон.

**Это не промышленный IP-блок. Сертификация соответствия не заявляется.**

[English version](README.md)

---

## Что это

Две части, которые проверяют друг друга:
1. **Побитово точная эталонная модель на Python** (`tb/can_fd_reference.py`): сборка кадров CAN и CAN FD, динамический стаффинг, поле stuff-count, CRC-15/17/21.
2. **RTL-ядро** (`rtl/`) — передатчик, приёмник, двухфазный битовый тайминг — и обёртка loopback, используемая как DUT №1.

Каждое утверждение в репозитории опирается на прогон, лог которого лежит в `logs/`.

## Архитектура

| Путь | Назначение |
|---|---|
| `rtl/can_fd_tx.sv` | Передатчик: фрейминг, динамический стаффинг, stuff count, CRC-15/17/21 |
| `rtl/can_fd_rx.sv` | Приёмник: дестаффинг, проверка CRC, проверка формы, драйв ACK |
| `rtl/can_bit_timing.sv` | Тайминг NBT/DBT, точка выборки, SSP, перепривязка при смене фазы |
| `rtl/can_fd_loopback.sv` | TX + RX через шину с dominant-AND |
| `tb/can_fd_reference.py` | Побитовый эталон на Python |
| `scripts/mutation_model.py` | Мутационный стенд над эталонной моделью |
| `scripts/verify_all.sh` | Полный прогон гейтов, пишет `logs/` |

Форматы: Classic CAN base/extended (CRC-15) и CAN FD base/extended (CRC-17 при DLC ≤ 8, CRC-21 при DLC ≥ 9), DLC 0–15, BRS вкл/выкл.

## Быстрый старт

Нужны: Verilator ≥ 5.0, cocotb ≥ 2.0, Python ≥ 3.10.

```bash
# Полный прогон гейтов. Пишет logs/ и печатает сводку.
bash scripts/verify_all.sh

# Мутационное тестирование модели (12 мутантов).
python3 scripts/mutation_model.py

# Юниты битового тайминга.
make -f Makefile.bittiming TEST_MODULES=tests.test_bit_timing

# Матрица реального двухфазного тайминга. SIM_BUILD обязателен отдельный.
make -f Makefile.loopback \
    SIM_BUILD=$PWD/sim_build_rt \
    EXTENDED=0 CLASSIC=0 \
    NBT_PRESCALER=1 NBT_TSEG1=12 NBT_TSEG2=4 \
    DBT_PRESCALER=1 DBT_TSEG1=3 DBT_TSEG2=1 \
    TEST_MODULES=tests.test_timing_matrix
```

## Известные ограничения

* **Fault confinement не реализован.** Счётчики TEC/REC, error frames и bus-off вне текущей области ядра.
* **Prescaler > 1 с очень короткой data-фазой.** При `NBT_PRESCALER=2` и `DBT=3` такта жёсткая синхронизация SOF может съехать на 1–2 такта. Это существовавшее ограничение ресинхронизации, а не регрессия.
* **Только симуляция.** Нет FPGA-сборки, нет кремния, нет квалификации ISO 26262.
* **2539 векторов BRS=1 отложены** в кросс-чеке осциллограмм — см. выше.
